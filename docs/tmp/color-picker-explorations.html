Color picker — explorations

Three layouts built on the same parts. They all work, and saved colors are shared between them (stored in this browser). Pick a layout, then tick the features you want in the list at the bottom.

Scrub fields: press on a number field and drag left/right. The cursor locks in place so it never runs out of room. Hold Shift for ×10 or Alt for ×0.1. A click without dragging edits the number as text. Format: the button left of the fields cycles HEX → OKLCH → RGB. Gradient stops: click the bar to add a stop, drag a stop to move it, drag it down off the bar (or press Delete) to remove it. Saved: + saves the current color, hover a chip and click × (or right-click it) to remove it.

A · Tabs

Solid / Gradient / Library tabs, like Untitled UI. Each tab stays short, and the big collections live in Library.

B · One sheet

A Solid/Gradient switch above the editor, and every collection as a collapsible section below it. dialkit-like: one scroll, no hidden tabs.

C · Swatches first

HeroUI-like: a narrow popover that opens on swatches (saved and traditional colors). The full editor sits behind "Custom". Icon tabs at the top.
