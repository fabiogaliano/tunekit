Select — exploring options without the open → pick → closed loop

Each card drives the ball's easing. The options are things you want to compare, so the question is how fast you can flip between them and see the result. A is today's uipane select; the rest are alternatives. Accent ball = previewing (not committed yet).

Recommendation

  • B + C together as the default select: the menu previews on hover/arrow keys (commit on click/Enter, revert on Esc or leaving the menu), and the closed trigger cycles with wheel, ←/→ while hovered, and ‹ › buttons. Browsing works in both states, and a single click still means "pick".
  • D automatically when there are ≤ 4 short options (or via { display: "chips" }). There's no menu to open at all.
  • E (scrub) fits uipane's drag-everything feel, but it can't be discovered by looking at it. Ship it as a modifier of C, not on its own.
  • F (pin) only helps with long lists, and B covers the same need with less UI.
